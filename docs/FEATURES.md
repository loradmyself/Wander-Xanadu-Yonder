# 功能规格（FEATURES）

> 状态：草案 v0.1 · 待评审
> 范围：平台固件（L1/L2）与工具运行框架（L2.5）；动态应用（L3）只列候选，另行确定
> 优先级：**P0** = v1.0 必须（缺了产品不成立）· **P1** = 应有（v1.x 补齐）· **P2** = 以后/可选

## 一、分层定义

| 层 | 内容 | 谁负责 | 是否进固件 |
| --- | --- | --- | --- |
| L0 | 芯片、SiFli SDK、RT-Thread、驱动 | SDK / 板级 | 是 |
| L1 | 平台底座：系统、显示、输入、音频、连接、存储、电源、USB | 平台组 | 是 |
| L2 | 平台服务：AI Core、语音链路、门户、OTA、安全 | 平台组 | 是 |
| L2.5 | 工具运行框架：清单、注册表、调度、权限、安装 | 平台组 | 是 |
| L3 | 动态应用（`.xzp`）：每个应用 = 页面 + 工具集 | 应用组 / 第三方 | 否，运行时安装 |

**判断标准**：凡是"没有它任何应用都跑不起来"的进 L1；凡是"多个应用都要用、但不该各写一遍"的进 L2；凡是"决定应用能不能被 AI 调用"的进 L2.5。

## 六、硬件前提（不满足则对应功能降级或删除）

| 功能 | 硬件前提 | 影响 |
| --- | --- | --- |
| USB Host（F-USB-07） | 5V VBUS 升压、限流开关、VBUS 检测脚、ESD 保护 | 缺一则只能做 Device |
| AEC / 降噪（F-AUD-06） | 双麦，或扬声器参考信号回采 | 单麦做不好，别承诺 |
| 电量计（F-PWR-02） | 库仑计或分压 ADC + 标定数据 | 无标定则电量跳变 |
| 表情动画（F-DISP-05） | LCD/AMOLED，非墨水屏 | 墨水屏只能做静态表情卡 |
| KWS 唤醒（F-INP-05） | 算力余量 + 模型存储 | 首版用按键 |
| 蓝牙音频（F-AUD-07） | 蓝牙协议栈支持 A2DP、PA 功放 | 无则走外放 |
| TF 卡（F-STO-02） | 卡座检测脚 + 电源开关 | 无则应用只能装内部 |

## 七、资源预算（需按实际配置核实）

| 项 | 估算 | 备注 |
| --- | --- | --- |
| 固件 + 平台 | 2–3 MB | 含 RT-Thread、LVGL、网络栈 |
| 中文字库 | 3–8 MB | 按字符集范围浮动，最大变量 |
| 表情 / 音效资源 | 2–5 MB | 序列帧比 Lottie 更占空间 |
| 应用安装区 | ≥ 8 MB | 按目标应用数量估 |
| Flash 合计建议 | ≥ 16 MB NOR | 低于此需外挂或裁剪字库 |
| PSRAM | ≥ 4 MB，建议 8 MB | LVGL 双缓冲 + 音频 + 流式文本缓冲 |
| 运行内存 | 稳态 < 60%，峰值 < 85% | 超过则休眠唤醒易失败 |

> 以上为估算区间，**必须按最终 BOM 与屏分辨率实测确认**，不能直接当结论用。
